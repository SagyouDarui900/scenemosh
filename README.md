# SceneMosh

AviUtl2 (拡張編集2) 用の高機能データモッシュプラグインです。タイムライン上のカット点（繋ぎ目）を検出し、前後のフレームのモーションベクター（動きベクトル）を操作して多彩なグリッチ映像を生成・自動配置します。C++20 で実装された `.aux2` 形式の汎用プラグインです。

[設計仕様書](DESIGN.md) | [ビルド手順](README_BUILD.md) | [English summary](#english-summary)

---

## 主な機能

- **カット点自動検出＆一括配置**: シーン内のクリップ境界（繋ぎ目）を自動検出し、選択した区間にワンクリックでグリッチオブジェクトを一括生成・配置できます。
- **全21種類のプリセット**: 定番のデータモッシュから、モーション転送、流体（溶融）、重力落下、波紋、ディレイ、ドリフトまで業界最多レベルの表現を搭載。
- **角度・方向パラメータ（Angle）**: 固定方向、ドリフト、重力、波紋、シフト、モーション転送などのエフェクト方向を 0〜360° で自由に指定可能。
- **2段階キャッシュ＆「グリッチのみ再適用」**: 中間素材とグリッチ処理後を分離キャッシュ。強度やシード、角度を変えた際は素材再エンコードをスキップし、数秒で結果を再生成できます。
- **Iフレーム抑制**: キーフレームの挿入を抑制し、前のカットの絵を次のカットへ引きずり続けるデータモッシュ本来の表現を実現。
- **解像度自動フィッティング**: 素材解像度とシーン解像度が異なる場合でも、高品質バイリニア補間でシーンサイズへ自動調整。
- **プレビュー完全対応**: 生成後はタイムラインのシークや前後移動に完全追従。

---

## 動作要件

- **AviUtl2**: 2.1.6a 以降（64-bit Windows 10 以降、DirectX 11、AVX2 対応 CPU）
- **FFglitch 0.10.2**: モーションベクター操作に `ffgac.exe` および `ffedit.exe` を使用します。初回利用時に自動ダウンロード確認ダイアログが表示されます（手動導入も可能。詳細は後述）。
- **ffmpeg.exe**（任意）: H.264 MP4 書き出し機能を利用する場合のみ必要です。

## インストール

1. [Releases](https://github.com/)（または配布 Zip）から `scenemosh.aux2` をダウンロードします。
2. AviUtl2 の `Plugin` フォルダに配置します。
   ```
   C:\ProgramData\aviutl2\Plugin\scenemosh.aux2
   ```
3. AviUtl2 を起動すると、メインメニューの「表示」内に **「SceneMosh」** パネルが追加されます。

## 使い方

SceneMosh には、**「① パネルからのカット一括配置」** と **「② メディアオブジェクトからの直接利用」** の 2 つの使い方があります。

### 1. SceneMosh パネルからの利用（カット一括検出・自動配置）

複数のカットにまとめてデータモッシュを適用する最も便利な方法です。

1. タイムライン上の同一レイヤーに動画クリップを並べ、カット（繋ぎ目）を作ります。
2. SceneMosh パネルで以下を設定します：
   - **対象レイヤー**: クリップが配置されているレイヤー番号（1〜）
   - **繋ぎ目前(f) / 繋ぎ目後(f)**: カット前後の取り込みフレーム数（合計フレーム数 = 前 + 後、初期値: 各30f）
   - **区間モード**:
     - `カット中心`: 繋ぎ目をまたぐ区間に適用（前のカットを引きずって次のカットを崩す定番演出）
     - `オブジェクト単位`: クリップ全体に適用
   - **プリセット**: 21種類から選択（対応プリセットでは「角度」欄が表示されます）
   - **強度 / seed / 角度**: パラメータを設定
3. **[1. カット点を検出]** をクリックします。タイムラインが走査され、繋ぎ目一覧が表示されます。
4. 一覧から適用したい区間を選択（複数選択可）し、**[2. 選択した区間を生成]** をクリックします。
   - ※初回のみ FFglitch の自動ダウンロード確認ダイアログが出ます。[はい] を押すと自動導入されます。
5. 生成完了後、**[3. 選択した区間を配置する]** をクリックすると、タイムラインの空きレイヤーに SceneMosh オブジェクトが自動配置されます。

---

### 2. メディアオブジェクトからの直接利用（詳細な調整）

タイムライン上で個別にエフェクトをかけたり、パラメータを微調整したい場合に使用します。

1. タイムラインの右クリックメニューから **[メディアオブジェクトの追加] → [SceneMosh]** を追加します。
2. 設定ダイアログで各項目を調整し、**[生成]** をクリックします。

#### 設定ダイアログの項目説明

| 項目 | 説明 |
|---|---|
| **参照モード** | **`レイヤー参照`**（標準）: 指定レイヤーの素材映像をそのまま取り込みます（高速・安定）。<br>**`画面キャプチャ`**: シーン全体の描画結果を取り込みます。**素材の拡大縮小・回転・移動アニメーションを反映させてモッシュさせたい場合はこちらを選択してください。** |
| **参照レイヤー** | 参照する動画クリップのレイヤー番号（1〜100）。 |
| **フレームオフセット** | 読み取り開始位置の微調整（-600〜+600f）。 |
| **繋ぎ目前(f) / 繋ぎ目後(f)** | カット前後の取り込み幅（合計フレーム数 = 前 + 後）。 |
| **プリセット** | 21種類のエフェクトから選択。 |
| **強度** | エフェクトの強さ（0〜100）。 |
| **seed** | 乱数シード（0〜100000）。 |
| **角度** | エフェクトの進行方向（0〜360°、対応プリセットのみ有効）。0°=右、90°=下、180°=左、270°=上。 |
| **Iフレーム抑制** | キーフレームの挿入を抑制し、前の絵を引きずり続けさせます（既定: ON）。 |
| **キャッシュフォルダ** | 空欄時はプロジェクト相対 `scenemosh_cache\`（未保存時は AppData）。 |
| **素通し表示** | 未生成時に元の参照映像をそのままプレビュー表示するかどうか（既定: OFF）。 |
| **未生成マークを表示** | 未生成時に市松模様のマゼンタ枠を表示するかどうか（既定: ON）。 |

#### 設定ダイアログのボタン機能

- **`[生成]`**: 中間映像のキャプチャ・エンコードからグリッチ処理までを一括実行します。
- **`[グリッチのみ再適用]`**: 既存の中間素材を再利用し、**ffedit の JS 処理と ffmpeg 変換のみを再実行**します。強度、seed、角度、プリセットを変更した際、再エンコードをスキップして数秒で結果を反映できます。
- **`[このキャッシュを削除]`**: 現在選択されている SceneMosh オブジェクトのキャッシュファイルのみを個別に削除します。
- **`[未使用キャッシュを削除]`**: プロジェクト内のどのオブジェクトからも使われていない古いキャッシュや一時ファイルを一括削除します。

## プリセット一覧（全21種類）

強度（0〜100）、seed、角度（0〜360°）の各対応状況です。

### 基本プリセット

| プリセット名 | 処理内容 | 強度の効果 | 角度 | seed |
|---|---|---|:---:|:---:|
| **MV増幅** | モーションベクターの大きさを乗算して動きを極端に強調します。 | 係数 `1.0 + 強度/25`（最大5.0倍）。 | - | - |
| **MV固定** | 全ブロックのベクターを一定値で上書きし、指定方向に均一に流します。 | 移動量（最大24px）。 | ✅ | ✅ |
| **MVランダム** | 全ブロックのベクターを一様乱数で撹拌し、砂嵐状のノイズを作ります。 | 乱数範囲 `±(1 + 強度/10)`。 | - | ✅ |
| **データモッシュ** | 繋ぎ目以降に直前の動きベクトルを継続適用し、前の絵が次の映像を侵食します。 | オブジェクトモード時の保持期間。 | - | - |
| **MV差分ドリフト** | フレーム経過に伴って指定方向への移動速度が徐々に加速していきます。 | 加速度 `0.05 + (強度/100)*0.45`。 | ✅ | ✅ |

### 応用プリセット

| プリセット名 | 処理内容 | 強度の効果 | 角度 | seed |
|---|---|---|:---:|:---:|
| **モーション転送** | **カット前の動きの推移を記録し、カット後の絵にそのまま流し込みます。** | 転送ベクターの強さ（100で等倍）。 | ✅ | - |
| **重力** | 動きのある部分を検出し、指定方向へ加速度をつけて落下・崩落させます。 | 1fあたりの重力加速度（最大2.0px/f²）。 | ✅ | - |
| **流体** | 過去フレームのベクターを移動平均して平滑化し、液体のように滑らかに溶かします。 | 平均化ウィンドウ（2〜16フレーム）。 | - | - |
| **波紋** | 空間的な正弦波歪みを加算し、水面のような波打ちを生成します。 | 振幅（最大12.0）および周波数。 | ✅ | - |
| **ディレイ** | 過去Nフレーム前のモーションベクターを遅延適用します。 | 遅延フレーム数（1〜30フレーム）。 | - | - |
| **バッファ** | 8フレーム前のモーションベクターを固定遅延適用します。 | 固定（8フレーム）。 | - | - |
| **ズーム** | 画面中心からの距離に応じて放射状にベクターを外向き拡大します。 | 画面隅での拡大率（最大2.0倍）。 | - | - |
| **シアー** | 行（Y座標）に応じて横方向のベクターをずらし、画面上下で逆方向に傾けます。 | 傾き係数（最大±0.5）。 | - | - |
| **シフト** | 画面全体を指定角度の方向へ一様に平行移動させます。 | 移動オフセット（最大±8px）。 | ✅ | ✅ |
| **スライス** | 水平ストライプ帯ごとに横ベクターの符号を反転させます。 | 反転割合（最大100%反転）。 | - | - |
| **スメア** | 水平ベクターのみ先頭フレームの値を固定し、横に引き伸ばします。 | - | - | - |
| **バイブレート** | 正弦波に基づき、水平・垂直方向に直交した周期振動を加算します。 | 振動振幅（最大8.0px）。 | - | - |
| **ミラー** | 指定確率でベクターの水平方向を反転させます。 | 反転確率（0〜100%）。 | - | ✅ |
| **シャッフル** | 近傍ブロック（±1ブロック）のベクターと位置を入れ替えます。 | 入れ替え確率（0〜100%）。 | - | ✅ |
| **ストップ** | ベクターを徐々に減衰させ、映像の動きを完全停止させます。 | 停止割合（100で完全静止）。 | - | - |
| **シンク** | 指定方向へ一定の引き込みオフセットを加算します。 | 沈降オフセット（最大+8px）。 | ✅ | - |

## よくある質問 (FAQ)

### Q. 動画素材が小さくなりながら（拡大率100→0）崩れるエフェクトを作りたいのに、サイズが変わりません
**A. 参照モードを `画面キャプチャ` に切り替えてください。**
デフォルトの `レイヤー参照` は、素材そのものの生映像（アニメーションが乗る前）を取り出す仕様です。拡大率や座標移動、回転などのキーフレームアニメーションを反映させたい場合は、設定ダイアログの **[参照モード] を [画面キャプチャ]** に変更して `[生成]` を押してください。

### Q. 強度やシード値を変えて試行錯誤したいのですが、毎回生成に時間がかかります
**A. `[グリッチのみ再適用]` ボタンを使ってください。**
素材の再エンコードをスキップし、ベクター操作と動画変換のみを行うため、数秒で新しい設定の結果が反映されます。

### Q. 不要になったキャッシュファイルを消したい
**A. パネルまたは設定ダイアログの `[未使用キャッシュを削除]` を押してください。**
タイムライン上で使われていない過去の生成ファイルや一時ファイル（`.part`）が一括削除されます。特定のオブジェクトだけ消したい場合は `[このキャッシュを削除]` を使います。

## FFglitch の入手と手動導入

FFglitch は GPL ライセンスのため、本プラグインには同梱されていません。
初回生成時に自動ダウンロード確認ダイアログが出ますが、手動で導入することも可能です：

1. [FFglitch 公式サイト](https://ffglitch.org/download/) より `ffglitch-0.10.2-windows-x86_64.zip` をダウンロードします。
2. 以下のフォルダを作成し、展開した `ffgac.exe` と `ffedit.exe` を配置します：
   ```
   %APPDATA%\scenemosh\ffglitch\
   (例: C:\Users\<ユーザー名>\AppData\Roaming\scenemosh\ffglitch\)
   ```

## ビルド方法

Windows（MSVC 2022、CMake）でのビルドに対応しています。

```sh
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

ビルド完了後、`build/Release/scenemosh.aux2` が生成されます。また、`build/Release/test_core.exe` で単体テスト（28テスト・557アサーション）を実行できます。

## English summary

SceneMosh is an AviUtl2 (ExEdit2) datamosh plugin (`.aux2`). It scans timeline cut points, manipulates MPEG-4 Part 2 motion vectors using FFglitch (`ffgac` and `ffedit`), and automatically places the resulting glitch clips onto the timeline. It features 21 presets (including Motion Transfer, Fluid, Gravity, Ripple, Delay, etc.), 360-degree angle control, 2-stage caching with rapid "Reglitch", screen capture support, and automatic bilinear resolution scaling. FFglitch 0.10.2 is downloaded on first use with user confirmation (SHA-256 verified) and is not bundled. License: MIT.
