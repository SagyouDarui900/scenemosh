# SceneMosh

AviUtl2 (拡張編集2) 用のデータモッシュプラグインです。タイムライン上のカット点を検出し、前後のフレームのモーションベクター（動きベクトル）を操作してグリッチ映像を生成し、タイムラインに自動配置します。C++20 で実装された `.aux2` 形式の汎用プラグインです。

[設計仕様書](DESIGN.md) | [ビルド手順](README_BUILD.md) | [English summary](#english-summary)

## 機能

- **カット点検出**: 指定したレイヤーを走査し、クリップの境界（繋ぎ目）を検出して区間一覧を作成します。区間の算出方法は「カット中心（前後の指定フレーム）」と「オブジェクト単位（クリップ全体）」から選択できます。
- **17種類のプリセット**: モーションベクターの増幅、固定、置換、遅延など、17種類の効果を選択できます。効果の強度（0〜100）と乱数シードを指定できます。
- **解像度の自動調整**: 前後クリップの解像度がシーン設定と異なる場合、アスペクト比（縦横比）を維持したバイリニア補間によりシーン解像度へ自動で拡大縮小します。
- **オフライン描画**: 各フレームを RGBA で描画し、パイプ経由で `ffgac` に渡して中間映像（MPEG-4 Part 2）を作成します。
- **2段階キャッシュ**: 素材の中間映像とグリッチ処理後の映像を分けて保存します。同一素材でプリセットや強度のみを変更して再生成する場合、中間映像のレンダリングを省略します。
- **タイムライン自動配置**: 生成した MP4 ファイルをタイムラインの空きレイヤーに自動で配置します。
- **MP4書き出し（任意）**: システム環境変数 `PATH` または指定パスに `ffmpeg.exe` が存在する場合、H.264 (libx264) 形式の MP4 を書き出せます。

## 動作要件

- AviUtl2 2.1.6a 以降（64-bit Windows 10 以降、DirectX 11、AVX2 対応 CPU）
- FFglitch 0.10.2: モーションベクター操作に `ffgac.exe` および `ffedit.exe` を使用します。プラグイン本体には同梱していません（詳細は [FFglitch の入手](#ffglitch-の入手) を参照してください）。
- ffmpeg.exe（任意）: H.264 書き出し機能を利用する場合のみ必要です。

## インストール

1. 配布 Zip（またはリポジトリの Releases）から `scenemosh.aux2` を取得します。
2. AviUtl2 の `Plugin` フォルダに配置します。
   例: `C:\ProgramData\aviutl2\Plugin\scenemosh.aux2`
3. AviUtl2 を起動すると、「SceneMosh」パネルが追加されます。

## 使い方

### パネルからの利用（一括検出・生成）

1. タイムライン上の同一レイヤーに動画クリップを配置し、カット（繋ぎ目）を作成します。
2. SceneMosh パネルで対象レイヤー番号、繋ぎ目前後のフレーム数（初期値: 各30フレーム）、区間モード（カット中心／オブジェクト単位）、プリセット、強度、seed を設定します。
3. [1. カット点を検出] をクリックし、一覧に表示された区間を選択します。
4. [2. 選択した区間を生成] をクリックします。初回のみ FFglitch の自動ダウンロード確認ダイアログが表示されます。
5. 生成完了後、[3. 選択した区間を配置する] をクリックすると、生成された動画がタイムラインに配置されます（「生成後に自動で配置する」が有効な場合は自動配置されます）。

### メディアオブジェクトからの利用

タイムラインの右クリックメニューからメディアオブジェクト「SceneMosh」を追加し、参照先レイヤーとプリセットを指定して [生成] を実行します。

## プリセット一覧

強度は 0〜100 の数値で指定します。`mv` はモーションベクターそのもの、`mv_delta` は前フレームからのベクトルの差分を操作対象とします。

### 基本プリセット

| モード名 | 処理内容 | 強度設定の影響 | seed |
|---|---|---|---|
| MV増幅 | モーションベクターの大きさを乗算します。 | 係数 `1.0 + 強度/25`（強度100で5.0倍）。 | 使用しない |
| MV固定 | 全マクロブロックのベクターを一定値で上書きします。画面全体が均一に流れます。 | 使用しない | 使用する（移動方向を決定）。 |
| MVランダム | 全マクロブロックのベクターを一様乱数で上書きします。 | 乱数範囲 `±(1 + 強度/10)`（強度100で±11）。 | 使用する（乱数の系列を決定）。 |
| データモッシュ | 最初の P フレームのベクターを以降の全フレームで保持します。先頭フレームの画像が動きに応じて変形し続けます。 | 使用しない | 使用しない |
| MV差分ドリフト | `mv_delta` に一定値を累積加算します。フレーム経過に伴い移動速度が増加します。 | 1フレームあたりの加算量 `0.05 + (強度/100)*0.45`。 | 使用する（ドリフト方向を決定）。 |

### 応用プリセット

| モード名 | 処理内容 | 強度設定の影響 | seed |
|---|---|---|---|
| ズーム | 画面中心からの距離に応じてベクターを外向きに拡大します。 | 画面隅での拡大率 `1.0 + 強度/100`（強度100で最大2.0倍）。 | 使用しない |
| シアー | Y座標（行）に応じて横方向のベクターを加算します。画面上下で逆方向に変形します。 | 水平オフセット係数 `(行 - 中心行) * (強度/100) * 0.5`。 | 使用しない |
| シフト | 画面全体に一様な横方向のオフセットを加算します。 | 水平オフセット量（強度100で最大±8ピクセル）。 | 使用する（シフト方向と大きさを決定）。 |
| スライス | 4行ごとの水平ストライプに対し、奇数番目の帯の横ベクターを反転させます。 | 水平乗数 `1 - 2*(強度/100)`（強度100で完全反転）。 | 使用しない |
| スメア | 水平方向のベクターのみ先頭フレームの値を保持し、垂直方向は現在のフレームに従います。 | 使用しない | 使用しない |
| バイブレート | 正弦波（サイン波）に基づき、水平・垂直方向に直交した周期振動を加算します。 | 振幅 `1.0 + 強度*7/100`（強度100で8.0）。 | 使用しない |
| ミラー | 指定確率で水平方向のベクターの正負を反転します。 | 反転確率 `強度/100`（強度100で全ブロック反転）。 | 使用する（対象ブロックの選定）。 |
| シャッフル | 各マクロブロックのベクターを近傍（±1ブロック）のベクターと入れ替えます。 | 入れ替え確率 `強度/100`。 | 使用する（入れ替え対象と方向の選定）。 |
| バッファ | 8フレーム前のモーションベクターを適用します。最初の8フレームはそのまま通過します。 | 使用しない（遅延量は8フレーム固定）。 | 使用しない |
| ディレイ | 指定フレーム数前のモーションベクターを適用します。 | 遅延フレーム数 `1 + (強度*29)/100`（強度100で30フレーム）。 | 使用しない |
| ストップ | ベクターの大きさを減衰させ、動きを停止させます。 | 減衰係数 `1 - 強度/100`（強度100で全ベクターが0）。 | 使用しない |
| シンク | 垂直方向のベクターに正（下方向）のオフセットを加算します。 | 下方向オフセット量 `round(強度*8/100)`（強度100で+8）。 | 使用しない |

※「MV固定」「データモッシュ」「スメア」「バッファ」は強度値を使用しません。
※「MV固定」「MVランダム」「MV差分ドリフト」「シフト」「ミラー」「シャッフル」以外は seed 値を使用しません。

## FFglitch の入手

FFglitch は GPL ライセンスのソフトウェアであるため、本プラグインには同梱していません。

初回生成時に以下の処理を行います：

1. `%APPDATA%\scenemosh\ffglitch`（通常は `C:\Users\<ユーザー名>\AppData\Roaming\scenemosh\ffglitch`）に `ffgac.exe` および `ffedit.exe` が存在するか確認します。
2. 存在しない場合、確認ダイアログを表示します。[はい] を選択すると、公式サイトより配布ファイル（`https://ffglitch.org/pub/bin/win64/ffglitch-0.10.2-windows-x86_64.zip`、約40MB）をダウンロードします。
3. ファイルサイズと SHA-256 ハッシュ値（`e5190462eafe9c28428d39f8392a6be93dfd6ac2d59ce08848edec79acf965ca`）を検証します。一致しない場合はファイルを破棄して処理を中止します。
4. アーカイブを展開し、`ffgac.exe` と `ffedit.exe` を上記フォルダに配置します。

手動で導入する場合は、あらかじめ公式サイトからダウンロードした `ffgac.exe` と `ffedit.exe` を上記フォルダに配置してください。配置済みの場合、ダウンロードは行われません。

## ビルド方法

Windows（MSVC 2022、CMake）でのビルドに対応しています。

```sh
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

ビルド完了後、`build/Release/scenemosh.aux2` が生成されます。また、`build/Release/test_core.exe` で単体テストを実行できます。

## English summary

SceneMosh is an AviUtl2 (ExEdit2) datamosh plugin (`.aux2`). It scans timeline cut points, manipulates MPEG-4 motion vectors using FFglitch (ffgac and ffedit), and automatically places the resulting glitch clips onto the timeline. It features 17 presets, 2-stage caching, and automatic bilinear resolution scaling. FFglitch 0.10.2 is downloaded on first use with user confirmation (size and SHA-256 verified) and is not bundled. License: MIT.
